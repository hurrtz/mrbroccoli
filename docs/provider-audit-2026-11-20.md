# Provider model audit, November 20, 2026

This audit covers all nine providers in the runtime manifest. Model cards, release
notes and API references were checked against the request paths Mr Broccoli uses.
OpenRouter’s public model and endpoint directories were also queried without
credentials. Request construction, response parsing, saved routes and the release
matrix were checked locally with fixtures. Account entitlements, regional
availability, model output and billing still require a credentialed request.

| Provider | Current routes and compatibility decisions |
| --- | --- |
| OpenAI | GPT-6.2 Astra and Sol launched November 17. Both accept chat, images and low, medium, high, extra-high or max reasoning. Medium is the default. GPT-6.1 Sol and Terra are also available. Only Terra in this set accepts disabled reasoning. Search continues through Responses. Recorded transcription defaults to `gpt-transcribe`. [Models](https://developers.openai.com/api/docs/models) · [Release history](https://developers.openai.com/api/docs/changelog) · [Transcription](https://developers.openai.com/api/docs/guides/speech-to-text) |
| Anthropic | Fable 5.2 (November 9), Sonnet 5.5 (September 28) and Haiku 5.5 (October 7) use Messages and `output_config.effort`. Fable and Sonnet default to high, Haiku to medium. Fable restricts forced tool choice, so the app retains its existing search model. Restricted Mythos access grants do not establish general key access. [Model comparison](https://platform.claude.com/docs/en/models/overview) · [Fable 5.2 changes](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2) · [Releases](https://www.anthropic.com/news) |
| Alibaba / Qwen | Qwen4-Max (November 16) supports images on regional OpenAI-compatible chat. `reasoning_effort` offers four distinct outcomes, none, low, high and extra high. High is the provider default. The app sets `preserve_thinking: false`. Existing search uses the separate Qwen Responses endpoint. Token Plan previews have different access conditions. Qwen-Audio ASR and synthesis use different speech contracts from the retired DashScope snapshots. [Qwen4-Max](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/qwen4-max) · [Chat contract](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions) · [Release history](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/newly-released-models) |
| Google Gemini | Neon (November 18), Hydrogen (November 12), Carbon (November 10) and Argon (October 13) accept images, text and recorded audio through GenerateContent. Neon and Hydrogen support four thinking levels up to extra high and default to high. Carbon and Argon accept three levels up to high and default to medium. Google enabled resource storage by default on new paid projects on October 26. The app explicitly disables it for chat, transcription, search and synthesis. The 3.8 Flash and Flash-Lite Interactions models remain Google's curated speech synthesis choices. [Release history](https://aistudio.google.com/docs/changelog) · [Neon](https://aistudio.google.com/docs/whats-new-gemini-4-neon) · [Hydrogen](https://aistudio.google.com/docs/whats-new-gemini-4-hydrogen) · [Carbon](https://aistudio.google.com/docs/whats-new-gemini-4-carbon) · [Argon](https://aistudio.google.com/docs/whats-new-gemini-4-argon) · [Storage](https://aistudio.google.com/docs/logs-datasets) |
| Mistral | Large 4 became generally available November 5. It accepts images, supports low, medium and high reasoning, and defaults to high. It replaces deprecated Medium 3.5 in the chat and search defaults. The October 20 Voxtral 3 public previews use the existing endpoints for Mini and Small recorded transcription and Mini speech synthesis. They support 53 transcription languages and 35 synthesis languages. Saved Voxtral 2 IDs retain their original languages and voices. [Large 4](https://docs.mistral.ai/models/mistral-large-4-0) · [Medium 3.5 lifecycle](https://docs.mistral.ai/models/mistral-medium-3-5-26-04) · [Voice migration](https://docs.mistral.ai/studio/audio/migrate-from-voxtral-2) · [Small Transcribe 3 model ID](https://docs.mistral.ai/models/voxtral-small-transcribe-3-0) · [Language tables](https://docs.mistral.ai/studio/audio/specs-and-limits/languages) |
| xAI | Grok 4.7 remains the newest general-purpose chat model. It supports low, medium, high and extra high, with high as its default. Grok 4.3 remains the search default. The standalone recorded-transcription and speech-synthesis APIs accept audio and voice parameters without an additional model selector. [Model catalogue](https://docs.x.ai/developers/models) · [Grok 4.7](https://docs.x.ai/developers/grok-4-7) · [Speech to text](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text) · [Text to speech](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech) |
| DeepSeek | Since October 17, `deepseek-flash` serves V4.1 Flash-1017 and accepts images. The current capability table lists text input for `deepseek-v4-pro`. The November 13 release adds standalone speech endpoints and optional server-side search for chat. Search needs a DeepSeek tool request and a parser for its citations. These capabilities sit outside the current chat adapter. [Current capabilities and prices](https://api-docs.deepseek.com/quick_start/pricing/) · [October model and search release](https://api-docs.deepseek.com/news/news261017/) · [November speech release](https://api-docs.deepseek.com/news/news261113/) |
| ElevenLabs | Scribe v3 (November 10) is the recorded-transcription default. Its multipart request accepts the same `model_id` and language fields as v2. Saved v2 selections remain available. Eleven v4 and v4 Turbo (September 28) also accept single-voice Create Speech requests. Flash v2.5 remains the existing synthesis default. Scribe v3 Live uses a WebSocket. [Scribe release](https://elevenlabs.io/blog/scribe-v3) · [Speech models](https://elevenlabs.io/docs/overview/models) · [Eleven v4 release](https://elevenlabs.io/blog/eleven-v4) · [Single-voice API support](https://elevenlabs.io/blog/elevenlabs-audio-tags-list) |
| OpenRouter | The public directory and per-model endpoint listings returned upstreams for each of the 22 existing routes and 15 newly curated snapshots. Additions cover the direct models above and Moonshot Kimi K3.1 Pro (October 23). The app stores canonical snapshot IDs. It uses OpenRouter's unified `reasoning.effort`, requires parameter support for explicit effort, and denies routes which collect user data. Kimi uses its upstream default because no discrete per-upstream effort range was established. [Model directory](https://openrouter.ai/api/v1/models) · [Endpoint directory contract](https://openrouter.ai/docs/api/api-reference/endpoints/list-endpoints) · [Reasoning controls](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens) |

## Retirements and release costs

- Google already serves Gemini 3.5 Flash requests with 3.6 Flash and Gemini 3.7 Flash requests with 3.8 Flash. Settings migrate these names to the actual serving models. The separate 2.5 Pro and Flash migrations start December 1. Google lists December 18 for the remaining 3.1 Flash TTS preview. [Deprecation schedule](https://aistudio.google.com/docs/deprecations)
- OpenAI schedules the three REST TTS choices for January 6, 2027. Its replacement uses a Realtime session. The older file transcription models retire February 26, 2027. [Speech migration](https://developers.openai.com/api/docs/guides/text-to-speech) · [Deprecation schedule](https://developers.openai.com/api/docs/deprecations)
- The full offline release plan reserves USD 2.0615 across its request matrix. Existing spend ceilings still apply before any billable request. Direct token price estimates use the cited provider's rates at the audit date. Google's introductory Carbon and Argon prices run through November 30. A reservation is an internal budget check, and the invoice depends on actual usage and the account.
