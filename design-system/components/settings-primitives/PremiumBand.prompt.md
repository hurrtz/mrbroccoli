The gold premium offer band — the one deliberately fancy surface in the product.

```jsx
<PremiumBand copy="Provider voices run on your own keys. One purchase, no subscription." onPress={openUpgrade} />
```

Gradient gold badge and button, a slow sweeping sheen, "Premium" wordline over one supporting sentence. It sits directly under the `locked` ghost rows it explains, and everywhere else premium is offered (overview, settings teasers). Every instance opens the same upgrade sheet. This is the only surface allowed animation-as-ornament; keep the copy factual — the free tier is never disparaged.
