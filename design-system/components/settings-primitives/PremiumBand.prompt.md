The gold premium offer band — the one deliberately fancy surface in the product.

```jsx
<PremiumBand copy="Provider voices run on your own keys. One purchase, no subscription." onPress={openUpgrade} />
```

Gradient gold badge and button, a slow sweeping sheen, "Premium" wordline over one supporting sentence. It sits directly under the `locked` ghost rows it explains, and everywhere else premium is offered (overview, settings teasers). Every instance opens the same upgrade sheet. Animation-as-ornament is reserved for the two invitation surfaces — this band and the intro banner; keep the copy factual — the free tier is never disparaged.

Premium honesty: the band may tease capabilities ("Every provider, web search…"), but wherever a provider capability is sold in detail, the copy states the user brings their own key — nothing is included automatically.
