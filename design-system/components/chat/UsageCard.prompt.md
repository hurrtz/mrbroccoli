Token usage for the turn, shown only when the user has turned usage statistics on.

```jsx
<UsageCard text="~1.2k prompt · 480 completion · ~1.7k total" />
```

One mono line in muted ink above a hairline — no icon, no title, no disclosure. It is an estimate, so the app's formatter keeps the `~`; exact counts drop it. The line is deliberately the quietest element in the message: usage is for the one user in fifty who wants it, and it must cost the other forty-nine nothing.
